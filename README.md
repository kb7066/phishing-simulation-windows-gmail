# Phishing Simulation & Security Detection & Mitigation
## Project Overview
This project simulates phishing attack in safe and controlled environment.
In this project I created fake phishing email sent by the Google Account Security Team advising a Gmail user to validate login information immediately, in response to suspicious activity detected on that account otherwise there account would be suspended. The goal of this project was to understand how phishing attacks work, how to detect them and mitigate them to reduce future threats.
## Objectives of the Project
- Understand how phishing emails trick users into providing sensitive information about themelves.
- Identify Event Viewer logs on computer and understand what the relevant Event Viewer ID means.
- Simulate a fake login page(phishing_sim.html?).
- Collect evidence through (screenshots, logs).
- Apply security mitigations.
- Document important events that occur and compile into an incident report.
